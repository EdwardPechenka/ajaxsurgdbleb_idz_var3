**Инструкция по запуску Дополнения к Лабораторной работе (AJAX с кэшированием)**

Чтобы всё работало корректно, выполни эти 5 простых шагов.

Шаг 1. Размещение файлов
Распакуй папку с проектом в директорию твоего локального веб-сервера (OpenServer).

Если у тебя старая версия OpenServer (5.x), это папка OSPanel\domains.

Если новая (6.0), это папка OSPanel\home.

<img width="663" height="33" alt="image" src="https://github.com/user-attachments/assets/61ad9a42-d4df-401c-8636-b4304f3c1571" />

Здесь не забудь создать папку ajaxsurgdbidz.local, это обязательно, и закинь туда все файлы (включая init_db.php и db.php с настройками под MySQL):

<img width="1090" height="438" alt="image" src="https://github.com/user-attachments/assets/97945068-c89b-4736-be0e-ec0b86249b34" />

Шаг 2. Загрузка базы данных (Если не сделано ранее)
Убедись, что твоя база данных iteh2lb1var4 активна в phpMyAdmin, либо просто запусти один раз в браузере скрипт автоматического развертывания таблиц: http://ajaxsurgdbidz.local/init_db.php.

Шаг 3. Конфигурация виртуального хоста (project.ini)
В папке проекта обязательно должен находиться файл project.ini со следующим содержимым, настроенным на актуальную версию PHP:

Ini, TOML
[ajaxsurgdbidz.local]
php_engine = PHP-8.4
public_dir = {base_dir}
Шаг 4. Запуск и проверка локального кэширования (localStorage)
Перезапусти OpenServer, открой браузер и перейди по локальному адресу проекта: http://ajaxsurgdbidz.local.

<img width="556" height="277" alt="image" src="https://github.com/user-attachments/assets/1c0f3159-4614-4d5f-8d75-9e5ebcfaa9a6" />

Чтобы продемонстрировать работу локального кэширования на стороне клиента (за выполнение которого даются 3 балла):

Выбери любой параметр (например, медсестру, отделение или смену) и нажми кнопку запроса. Первый запрос уйдет на сервер, отобразит результаты и автоматически запишет их в память браузера.

Выбери тот же самый параметр еще раз и нажми кнопку.

Результат отобразится мгновенно без повторного обращения к серверу, а рядом с результатами загорится зеленая текстовая метка: (Из локального кэша).

<img width="749" height="752" alt="image" src="https://github.com/user-attachments/assets/dbd475b1-fa34-4c8a-a22b-092b931d3933" />

Шаг 5. Просмотр сохраненных данных в браузере
Чтобы наглядно показать преподавателю, где именно хранятся эти данные:

Нажми клавишу F12 (или кликни правой кнопкой мыши -> Посмотреть код).

Перейди во вкладку Application (Приложение) -> в левой колонке разверни Local Storage -> выбери адрес сайта http://ajaxsurgdbidz.local.

<img width="1102" height="847" alt="image" src="https://github.com/user-attachments/assets/f79631df-afc4-4f09-9374-75f359b3b5c7" />

В таблице отобразятся сгенерированные ключи кэша (ajax_nurse_1, ajax_dept_1, ajax_shift_First), внутри которых физически сохранены структуры Text, XML и JSON.

<img width="923" height="133" alt="image" src="https://github.com/user-attachments/assets/53463f08-b4fa-4414-a0f2-c24a3ccb225c" />

🛠 Частые ошибки:
Зеленая метка кэша не появляется при первом клике: Всё правильно. При первом выборе параметра данных в памяти браузера еще нет, поэтому скрипт делает стандартный AJAX-запрос к серверу. Метка появится начиная со второго нажатия на ту же кнопку.

Данные в кэше устарели: Если ты изменил что-то в базе данных и хочешь сбросить кэш браузера, просто зайди в панель F12 -> Application -> Local Storage, кликни по ключу правой кнопкой мыши и нажми Delete, либо полностью очисти историю браузера.
